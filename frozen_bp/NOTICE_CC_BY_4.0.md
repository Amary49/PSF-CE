# Attribution notice for redistributed UCI-derived frozen pools

The six files under `frozen_bp/iris/` and `frozen_bp/mushroom/` are frozen experimental artifacts derived from datasets distributed by the UCI Machine Learning Repository under the Creative Commons Attribution 4.0 International license.

- R. A. Fisher, *Iris* [Dataset], UCI Machine Learning Repository, DOI: 10.24432/C56C76.
- *Mushroom* [Dataset], UCI Machine Learning Repository, DOI: 10.24432/C5959T.
- License: https://creativecommons.org/licenses/by/4.0/

Modifications represented by these artifacts include deterministic preprocessing and generation of base-partition label arrays. The NPZ files also retain the corresponding integer ground-truth label vector used by the formal evaluation. No original feature matrix is included.

This notice covers only these UCI-derived data artifacts. PSF-CE project-authored source code is separately released under the root MIT `LICENSE`; this notice does not relicense any third-party baseline implementation.
